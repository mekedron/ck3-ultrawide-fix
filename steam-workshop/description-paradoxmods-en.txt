Ultrawide Pause Menu Fix

The in-game pause menu (Esc) does not fit on the screen on ultrawide and super-ultrawide displays — the logo, the buttons and the version number get cut off at the top and bottom. The main menu is fine; only the pause menu is affected.

THE CAUSE

gui/frontend_ingame_menu.gui scales its content with ScaleToFitElementOutside, which is a "cover" fit: max(width / 1920, height / 1080).

On a 5120x1440 screen that comes out as max(2.67, 1.33) = 2.67, so the roughly 830px tall menu column is blown up to about 2200px and no longer fits into 1440px of screen height. The wider the display, the worse the overflow.

Every other fullscreen frontend layout in the game — the main menu, the bookmark screen, the barbershop — uses ScaleToFitElementInside instead. That is exactly why the main menu looks correct and only the pause menu breaks.

THE FIX

This mod overrides that one file and changes three lines on a single widget:

- ScaleToFitElementOutside becomes ScaleToFitElementInside, so the menu is scaled to fit the screen instead of covering it
- the reference frame is a fixed 1920x1080 box instead of the full screen
- that frame is centered instead of anchored to the left edge

The last two mirror how frontend_main.gui is built, so the menu column ends up in the same horizontal position as in the main menu rather than hugging the left edge of a very wide screen. The background art is drawn by the window itself and still covers the whole screen.

NOTES

- On 16:9 displays the result is identical to vanilla — both fits produce the same scale factor there, so nothing changes for regular monitors
- GUI-only mod: no gameplay, script or history files are touched, so ironman and achievements are unaffected
- Safe to add or remove at any time, including mid-campaign — it does not touch save games
- Built for CK3 1.19.x. GUI overrides replace the vanilla file wholesale, so if a future patch reworks the pause menu, this mod will need an update

COMPATIBILITY

Replaces gui/frontend_ingame_menu.gui in full. It conflicts only with mods that edit that same file; if you use one, place this mod below it in the load order to keep the fix, or above it to keep the other mod's changes.
